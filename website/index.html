Why Ferrite?

🧠

ML-First Design

Tensor types with compile-time shape validation. Dedicated train and infer effect blocks built directly into the language semantics.

🛡️

Strict Typing

Zero implicit coercion, zero truthiness, and zero runtime reflection. If it compiles, the types and memory align perfectly.

⚡

Dual Execution

Run scripts instantly using the pure-Rust Tree-Walk Interpreter, or compile ahead-of-time to blazing fast native code via LLVM.

🧩

Modern Paradigms

Algebraic Data Types (Enums), Trait implementations, closures, and deep structural pattern matching with guard clauses.

Clean, Expressive Syntax

Groups & Traits

group Point {
    x: float;
    y: float;
}

trait Add {
    fun add(self, other: Self) -> Self;
}

impl Add for Point {
    fun add(self, other: Self) -> Self {
        return Point {
            x: self.x + other.x,
            y: self.y + other.y
        };
    }
}
Closures & Loops

// First-class functions & lexical capture
keep offset: int = 100;
keep adder: fun(int)->int = (x: int) => x + offset;

// Advanced loop control
keep i: int = 0;
while i < 10 {
    i = i + 1;
    if i == 3 { skip; } // continue
    if i == 8 { stop; } // break
    println(str(adder(i)));
}
