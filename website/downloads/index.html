macOS

🐧

Linux

Ubuntu, Fedora, Arch, etc.

curl -fsSL https://ferrite-lang.org/install.sh | sh

Build from Source

Require a custom build? Make sure you have the Rust toolchain installed. 

git clone https://github.com/vishwanathdvgmm/ferrite.git
cd ferrite
cargo build --release
